# Поиск услуг Авито

По запросу нахожу до 50 объявлений из benchmark. Сначала несколько поисковых методов
собирают кандидатов, затем CatBoost выбирает итоговые 50. Качество оцениваю по Recall@50:
средней доле найденных положительных объявлений по всем запросам, включая пустые выдачи.

**Итоговый Recall@50 на площадке -- 0.822587.** Результат получен после отправки
текущего `answer.csv`; файл и его SHA-256 зафиксированы в
[записи результата](outputs/submissions/submission_result.json).

## Ноутбуки

Запускаю сверху вниз, по порядку. Весь код находится здесь, папок src и scripts нет.

| Ноутбук | Что делаю |
|---|---|
| `01_EDA` | Проверяю схему, пропуски, повторы, распределения, выбросы, сдвиги, пересечения, корреляции и PCA |
| `02_feature_engineering` | Готовлю каталог и разбиение; описываю основные 80 и дополнительные 21 признак |
| `03_baselines` | Популярность, overlap, TF-IDF, BM25, история, Naive Bayes; объединение RRF и удаление источников |
| `04_dense_retrieval` | Локальный E5, поиск сложных неразмеченных примеров, адаптер запросов |
| `05_catboost` | Собираю признаки кандидатов, сравниваю два набора, проверяю важности; обучаю финальную модель |
| `06_linear` | Проверяю логистическую модель на тех же признаках |
| `07_ranker` | Проверяю QuerySoftMax с группировкой по запросу |
| `08_mlp` | Проверяю небольшую сеть над теми же признаками |
| `09_ensemble` | Сравниваю смешивание рангов и stacking, сохраняю и проверяю `answer.csv` |

В 02 и 03 ячейки с общими функциями помечены `definitions`. Другие ноутбуки читают только
эти ячейки через nbformat; расчеты и обучение из соседнего ноутбука при этом не запускаются.
Так формулы остаются в одном месте. Переменные экспериментов имеют разные префиксы.
06--08 зависят от 05, но не друг от друга. Для 09 нужны результаты всех трех.

## Запуск с нуля

Проверенное окружение -- Python 3.12. Точные версии сохранены в `requirements.lock.txt`,
допустимые диапазоны -- в `requirements.txt`. В корне создаю отдельное окружение:

```bash
python3.12 -m venv .venv312
source .venv312/bin/activate
python -m pip install -r requirements.lock.txt
python -m ipykernel install --user --name avito312 --display-name 'Avito Python 3.12'
jupyter lab
```

В `dataset/` кладу три исходных файла: `train.parquet`, `benchmark_queries.parquet`,
`benchmark_items.parquet`. Другой путь можно передать через переменную `AVITO_DATA_DIR`.
В Jupyter выбираю ядро Avito Python 3.12 и выполняю ноутбуки 01--09 целиком.
Рабочая директория -- корень репозитория или папка notebooks.

Автоматический запуск из корня после активации окружения:

```bash
for notebook in notebooks/0*.ipynb; do
  jupyter nbconvert --to notebook --execute --inplace \
    --ExecutePreprocessor.kernel_name=avito312 \
    --ExecutePreprocessor.timeout=-1 "$notebook" || break
done
```

04 использует multilingual-e5-small с фиксированной ревизией из
`outputs/models/dense_manifest.json`. Если весов нет, скачиваю их при первом запуске 04.
После подготовки весов обучение и инференс работают локально, без внешних API.
Это единственное предобученное состояние, нужное чистому запуску.
Индексы, признаки, адаптер и модели рассчитываются из исходных Parquet.
E5 кодирует весь каталог, поэтому первый запуск заметно дольше повторного.

## Результаты и отправка

Итоговый файл -- `outputs/submissions/answer.csv`. Его формирует 09 из результата 05.
В `validation.json` рядом сохраняется проверка: ровно нужные query_id, допустимые item_id,
не больше 50 уникальных объявлений, две колонки, корректные строки и разделители.
На площадку загружаю только этот CSV. Автоматической отправки в решении нет.
На площадке этот файл получил **0.822587**. Дополнительные признаки выиграли на dev,
но не на локальном test; все три результата сохраняю отдельно в отчете об экспериментах.

Таблицы экспериментов находятся в `outputs/validation/`, графики -- в `outputs/figures/`,
модели -- в `outputs/models/`. Промежуточные матрицы и кандидаты -- в `outputs/cache/`.
Кеш можно пересоздать запуском всей цепочки. Исторические ответы для нее не нужны.

Локальные метрики не подменяют результат закрытого benchmark.
